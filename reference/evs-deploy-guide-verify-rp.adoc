= NetApp Disaster Recovery 에서 모든 것이 제대로 작동하는지 확인하세요.
:allow-uri-read: 


[role="lead"]
NetApp Disaster Recovery에 복제 계획을 추가한 후에는 계속 진행하기 전에 계획이 *정상* 상태인지 확인하십시오.

그림: 복제 계획 페이지image:evs-replication-plan-post-create.png["복제 계획 페이지"]

NetApp Disaster Recovery는 ONTAP 클러스터, vCenter 클러스터 및 VM을 포함한 모든 구성 요소에 액세스할 수 있고 보호 준비가 완료되었는지 확인하기 위해 일련의 테스트를 실행합니다. 이를 규정 준수 검사라고 하며 정기적으로 실행됩니다.

복제 계획 페이지에는 다음 정보가 표시됩니다.

* 마지막 준수 검사 상태
* 복제 계획의 복제 상태
* 보호된 (소스) 사이트의 이름
* 복제 계획으로 보호되는 리소스 그룹 목록
* 장애 조치(대상) 사이트의 이름
