= NetApp Disaster Recovery 에 온프레미스 및 Amazon EVS vCenter 클러스터 추가
:allow-uri-read: 


[role="lead"]
사이트를 생성한 후, NetApp Disaster Recovery에서 각 사이트의 vCenter 클러스터를 추가합니다. 사이트 유형에 따라 해당 사이트의 vCenters에 대해 NetApp Disaster Recovery가 요구하는 액세스 권한이 결정됩니다. Amazon EVS vCenters 및 온프레미스 vCenters는 동일한 연결 및 인증 정보를 사용합니다.

.각 사이트에 vCenter를 추가하는 단계
. *사이트* 옵션에서 원하는 사이트에 대해 *vCenter 추가*를 선택합니다.
+
image:evs-add-vcenter-1.png["vCenter 옵션 추가"]

. vCenter 서버 추가 대화 상자에서 다음 정보를 선택하거나 제공합니다.
+
.. AWS VPC 내에 호스팅된 NetApp Console 에이전트입니다.
.. 추가할 vCenter의 IP 주소 또는 FQDN입니다.
.. 필요한 경우, 포트를 vCenter 서버에서 사용하는 TCP 포트로 변경하십시오.
.. NetApp Disaster Recovery 에서 vCenter를 관리하는 데 사용할 이전에 만든 계정의 vCenter 사용자 이름입니다.




. 조직에서 외부 인증 기관(CA) 또는 vCenter 엔드포인트 인증서 저장소를 사용하는 경우 *자체 서명 인증서 사용* 옵션의 선택을 해제하십시오. 그렇지 않은 경우 해당 옵션을 선택한 상태로 두십시오.
+
.. *추가*를 선택하세요.
+
