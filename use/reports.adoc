= NetApp Disaster Recovery에서 보고서 생성
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/use/


[role="lead"]
NetApp Disaster Recovery 보고서를 사용하여 재해 복구 준비 상태를 평가하십시오. 보고서에는 각 복제 계획이 포함하는 리소스 그룹, VM, Kubernetes 클러스터 및 데이터 저장소 수를 비롯한 복제 계획에 대한 세부 정보가 제공됩니다. 또한 규정 준수 상태, 작업 요약, 복구 시점 목표(RPO) 및 보존 기간 등 백업 설정도 표시됩니다.

사고 발생 전에 보고서를 활용하여 복제 규정 준수 및 복구 이력을 평가하고 보호 허점을 파악하십시오.


TIP: link:dashboard-view.html["대시보드에서 전체적인 보호 상태를 확인하거나 워크로드 페이지에서 워크로드별로 보호 상태를 확인할 수 있습니다."]

== 재해 복구 보고서 정보

PDF, HTML 또는 JSON 형식으로 보고서를 다운로드할 수 있습니다.

보고서 다운로드 링크는 생성 후 6시간 동안 유효합니다.

.단계
. link:https://console.netapp.com/["NetApp Console"^]에 로그인하십시오.
. NetApp Console 왼쪽 탐색에서 *보호* > *재해 복구*를 선택합니다.
. NetApp Console 왼쪽 탐색 모음에서 *복제 계획*을 선택합니다.
. *보고서 만들기*를 선택하세요.
. 보고서 범위를 Kubernetes, VMware 또는 전체 중 어떤 *워크로드*로 지정할지 선택합니다.
. 보고서의 *파일 형식*(PDF, HTML 또는 JSON)과 *기간*(지난 1일~7일)을 선택합니다.
+
image::report.png[보고서 생성 화면 캡처]

. 보고서를 생성하려면 *생성*을 선택합니다.
+

NOTE: 보고서를 생성하는 데 몇 분 정도 소요될 수 있습니다.

. 복제 계획 대시보드에서 *보고서 다운로드*를 선택합니다.
